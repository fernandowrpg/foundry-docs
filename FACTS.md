# Verified facts (from foundryvtt.com release notes + API docs, Sept 2026)

## Versions
- V13 stable: 13.341 (Apr 27 2025) … latest 13.351 (Nov 12 2025). Node 20 required (22 supported), Electron 33.
- V14 stable: 14.359 (Apr 1 2026) … latest 14.368 (Sep 16 2026). V14 cannot update in-place from V13 (reinstall).
- API docs: https://foundryvtt.com/api/v13/ , https://foundryvtt.com/api/v14/
- Deprecated globals from V13 namespacing remain until V15. V12 deprecations removed in V14.

## V13 (vs V12) — developer highlights
- ALL core apps moved to ApplicationV2 + Theme V2 (dark/light, auto from OS). CSS Layers for styles. jQuery deprecation underway.
- Default core actor/item sheets registrations removed (systems MUST register their own sheets; no AppV1 fallback).
- Classes moved to ESModules with `foundry.<group>` namespaces (globals deprecated until V15): e.g. `foundry.canvas.placeables.Token`, `foundry.canvas.layers.*`, `foundry.applications.api.ApplicationV2`, `foundry.applications.api.HandlebarsApplicationMixin`, `foundry.applications.api.DialogV2`, `foundry.applications.api.DocumentSheetV2`, `foundry.applications.sheets.ActorSheetV2`, `foundry.applications.sheets.ItemSheetV2`, `foundry.applications.apps.DocumentSheetConfig`, `foundry.applications.handlebars.loadTemplates`, `foundry.applications.ux.TextEditor.implementation.enrichHTML`, `foundry.applications.ux.DragDrop`, `foundry.applications.ux.ContextMenu`, `foundry.documents.collections.Actors`, `foundry.documents.collections.Items`.
- Sheet registration V13+: `foundry.applications.apps.DocumentSheetConfig.registerSheet(Actor, "forja", ForjaActorSheet, { types: ["character"], makeDefault: true, label: "FORJA.SheetCharacter" })` (also `foundry.documents.collections.Actors.registerSheet("forja", Cls, {...})`). Unregister core: `DocumentSheetConfig.unregisterSheet(...)`.
- AppV2 static `TABS` config + `_prepareTabs(group)`; `static PARTS` for HandlebarsApplicationMixin; `DEFAULT_OPTIONS.actions` map to `data-action` attributes; `form: { submitOnChange: true, closeOnSubmit: false }`; `window: { resizable, icon, title, contentTag, controls }`; `position: { width, height }`. `ApplicationV2#submit` returns handler values. `options.window.contentTag`. Hook `getHeaderControls{ClassName}(app, controls)`. `HandlebarsApplicationMixin` template parts support `root: true`. `.theme-dark` / `.theme-light` classes. `DocumentSheetV2` "editImage" action. `ActorSheetV2` extensible drag & drop framework (`_onDrop`, `_onDropItem`, `_onDropActiveEffect`, `_onDropActor`, `_onDropFolder`, `_onSortItem`). ActorSheetV2 actions: `configurePrototypeToken`, `configureToken`, `showPortraitArtwork`, `showTokenArtwork`.
- `SceneControls#controls` is now a RECORD (object keyed by name) not array → affects `getSceneControlButtons` hook.
- New `user` setting scope (per-user, synced across clients). `Symbol` not allowed as setting type.
- Roll modes no longer applied in `ChatMessage#_preCreate` unless `options.rollMode` set.
- `DocumentOwnershipField` uses `gmOnly`; `DocumentAuthorField` for `ChatMessage#author`, `Macro#author`, `Drawing#author`.
- `StringField._getChoices` → `StringField._prepareChoiceConfig`.
- `foundry.utils.deepFreeze`, `foundry.utils.deepSeal`; `User#isActiveGM`; `Users#getDesignatedUser`, `User#isDesignated`.
- `HTMLCodeMirrorElement` (code editor); `progress` notification type (`ui.notifications.info(msg, {progress:true})`), `displayProgressBar` deprecated.
- Token drag measurement: waypoints, movement actions (`CONFIG.Token.movement.actions`), `TokenDocument#move`, `measureMovementPath`, `stopMovement/pauseMovement/continueMovement`, `movementHistory`, `getSnappedPosition`, `getCenterPoint`, `getOccupiedGridSpaceOffsets`, `Token#findMovementPath`, `Token#constrainMovementPath`. `Token#getSize` → `TokenDocument#getSize`. `Token#testInsideRegion` → `TokenDocument#testInsideRegion`. `ElevatedPoint` {x,y,elevation}. `CONFIG.Token.movement.defaultSpeed`.
- Region behavior `Modify Movement Cost`. `RegionDocument#teleportToken`. `Region.REGION_MOVEMENT_SEGMENT_TYPES` → `CONST.REGION_MOVEMENT_SEGMENTS`.
- Combat turn markers, animated doors, light priority, sound-reactive lights.
- `PlaceableObject.implementation`, `foundry.utils.getPlaceableObjectClass`.
- `CalendarData#add`. `Combat#_onEnter`, `Combat#_onExit`.
- `MACRO_SCRIPT` permission restricts creation only, not execution.
- `appendNumber` / `prependAdjective` moved from Token to PrototypeToken.
- User queries: `CONFIG.queries[name] = async (data, {timeout}) => ...` and `user.query(name, data, {timeout})` (V13).

## V14 (vs V13) — developer highlights
### Big features
- **Scene Levels**: one Scene stacks multiple Levels (images at elevations). New `Level` document/class (global `Level`), `Level#background/#foreground/#fog`, `Level#edges`, `Scene#getSurfaces`, `Scene#testSurfaceCollision`, `BaseEffectSource#level`, `SceneManager#_determineInitialLevel`, `CONFIG.Canvas.managedScenes` supports `SceneManager` instances. Scene Config: new Basics tab + Levels tab. Shared fog exploration mode.
- **Pop-out applications**: ApplicationV2 can render in a separate browser window. `ApplicationV2.instances` generator.
- **Placeables Palette** (bulk edit) and **Placeables sidebar tab**.
- **Active Effects V2**: `ActiveEffect#changes` MIGRATED to `ActiveEffect#system#changes` (i.e. `effect.system.changes`). Change `mode` (number) migrated to string `type`. `CONST.ACTIVE_EFFECT_CHANGE_TYPES` = { custom:0, multiply:10, add:20, subtract:20, downgrade:30, upgrade:40, override:50 } (values are default priorities). Change phases `CONST.ACTIVE_EFFECT_CHANGE_PHASES` = "initial", "final" (packages can register more and apply via `Actor#applyActiveEffects()`). ActiveEffectChangeData: { key, value, type, phase, priority }. `EffectChangeData#value` deserialized (JSON parse or string). Duration now `{ value, units, expiry, expired }` with units in `CONST.ACTIVE_EFFECT_DURATION_UNITS` (years, months, days, hours, minutes, seconds, rounds, turns); expiry events `CONST.ACTIVE_EFFECT_EXPIRY_EVENTS` = combatStart, roundStart, turnStart, combatEnd, roundEnd, turnEnd (custom ones allowed). `ActiveEffect.registry` (ActiveEffectRegistry) tracks temporary effects expiry. `ActiveEffect#origin` is a `DocumentUUIDField`. Active Effects are now PRIMARY documents: can live in the sidebar/compendiums; drop an effect on a Token to apply to its Actor. `CONFIG.ActiveEffect.legacyTransferral` REMOVED. Actor field `tokenOverrides` lets effects change token vision, light, image, alpha, disposition, size, shape. Static helpers `ActiveEffect.applyChange`, `applyChangeField`, `fromStatusEffect`, `shouldApplyChange`, `CHANGE_TYPES`, `CHANGE_PHASES`, `EXPIRY_EVENTS`. `CONFIG.statusEffects` is now an OBJECT `{ [id]: StatusEffectConfig }` (array still backwards compatible).
- **Template Regions**: `MeasuredTemplate` document type REMOVED/absorbed into Scene Regions. Regions gain shapes: line, cone, ring (`RingShapeData`), emanation (`EmanationShapeData`), token (`TokenShapeData`), grid (`GridShapeData`); grid-based mode; attach to tokens `RegionDocument#attachment.token` (was briefly `attachedToken`); `RegionDocument.createTokenEmanation()`; `RegionLayer#placeRegion(s)` with `attachToToken`, `onChange`, `allowEmpty`; ActiveEffect region behavior (applies effects to entering tokens); `RegionDocument#teleportTokens`, `#spawnTokens` (`{create:false}` ephemeral, `avoidOccupied`); ownership field + `REGION_CREATE` permission; Restriction type/priority; default visibility `LAYER_UNLOCKED` for non-template regions. `RegionShape` deprecated → `BaseShapeData` mixins; `foundry.data.regionShapes.RegionPolygonTree` → `foundry.data.PolygonTree`.
- **Chat Message Visibility Modes** replace Roll Modes (any message, plus "In-Character" mode). `ChatMessage.applyMode(chatData, mode)` (static) and `message.applyMode(mode)`; modes "public", "self", "gm", "blind". `Roll#toMessage(messageData, { create, messageMode })` — option renamed from `rollMode` to `messageMode`. Back-compat until V16. `ChatLog.MESSAGE_PATTERNS` → `ChatLog.CHAT_COMMANDS` (removed in V16). Chat input is an inline ProseMirror editor.
- **VFX**: `foundry.canvas.vfx` timeline animations (animejs as `globalThis.animejs`), `ParticleGenerator`, `animation.CanvasShakeEffect` (screen shake), Scene Transitions (14 animations), `Scene#activate({viewOptions, pullUsers})`.
- Performance +3–25% on common ops. Font Awesome 7.2.0. TinyMCE removed (ProseMirror only; `foundry.prosemirror.defaultPlugins` → `foundry.applications.ux.ProseMirrorEditor.buildDefaultPlugins()`).
### Data / documents
- `template.json` enters DEPRECATION → systems must use `documentTypes` in manifest + `TypeDataModel` (`CONFIG.<Doc>.dataModels`) or unspecified schema.
- Package manifest gets optional explicit `"type": "system" | "module"` field.
- Document metadata can control whether the "base" type may be created / offered in create dialogs.
- `DataModel#updateSource` special keys `-=` / `==` DEPRECATED for `DataFieldOperator` values (e.g. `foundry.data.operators`… check API). Use `ForcedDeletion`/`ForcedReplacement` style operators; in V13 use `"-=key": null` / `"==key": value`.
- `DataModel#_updateDiff`, `DataModel#_updateCommit` lifecycle; `DataModel.cleanData` options; `SchemaField#extendFields`, `#removeFields`; `DataModel#getFieldForProperty(key)`; `DataField#placeholder` (auto-localized).
- `Document.create` uses `this.implementation`; `Document#persisted`; relative UUIDs `foundry.utils.buildRelativeUuid`, `DocumentUUIDField#relative`; `DatabaseOperation.documentName`.
- `TypeDataModel#onEmbed` callback (called by `ClientDocument#onEmbed`).
- `User.queryMany` (query several users); sender id passed to query handlers.
- `foundry.utils.equals()` replaces `objectsEqual`; `foundry.utils.isPlainObject`; `diffObject(..., {bidirectional})`; `debounce().cancel()`; `closestPointToPath`. `Collection` uses native Iterator Helpers. `RegExp.escape` polyfill removed (native).
- Localization: `game.i18n.localize()` merged with `format()` (localize accepts data); global alias `_loc(key, data)`. `LOCALIZATION_PREFIXES` added for BaseDrawing/BaseJournalEntryPage. Compendium titles localized in search.
- `TokenDocument#detectionModes` → `TypedObjectField`. `ActorDelta` can be null. `MacroData#author` nullable. `DocumentStatsField#createdTime/modifiedTime` required. `DocumentCollection#importDocument` keeps IDs; batch writes across collections.
- Hooks: `ready` fires AFTER scene transitions finish. `planToken` hook; `preRender` hook. `CalendarData#onUpdateWorldTime`.
### Canvas / tokens
- `TokenDocument#depth`, `getMovementOrigin/VisionOrigin/LightOrigin/SoundOrigin`, `getListenerPosition`, `startMovement`, planned movement `token.planMovement(options)`, `Scene#moveTokens`, `TokenLayer#placeTokens`, `TokenDocument#move` resolves when finished, `TokenMovementData#finished`. `TokenFindMovementPathOptions` `ignoreWalls/ignoreCost/history` deprecated → `constrainOptions`. `TokenMovementActionConfig#getAnimationOptions(tokenDocument)` (was Token). `WallDocument#isDoor`, `#isOpen`. `Scene#gridlessGrid`; `BaseGrid#getRectangle/getLine/getEllipse`. `layerClass` in Canvas Document CONFIG deprecated. `PlaceableObject#isInteractable` (locked placeables non-interactable). `PlaceableObject#clear` deprecated → `_clear`. `SceneControls#tool` / `game.activeTool` can be null. `SceneControlTool` gains `interaction`, `control`, `creation`, `shapeData`. `TokenRuler#_getWaypointStyle`. `ClockwiseSweepPolygonConfig#edgeOptions` → `#edgeTypes`; `CONST.EDGE_SENSE_TYPES`, `EDGE_RESTRICTION_TYPES`, `EDGE_DIRECTIONS`, `EDGE_DIRECTION_MODES`. TileDocument anchorX/anchorY (position = x,y). Adaptive/Natural light attenuation.
### UI
- `HeaderControls` and `ContextMenu` unified; `ContextMenuEntry#icon` accepts class names. `AppV2#_canRender` first-render flag. `auxclick` support. `parseHTML` returns null on failure. `<code>` inline by default (`block` class for block). `highlightElement(el, opts)`. `HTMLFormulaInputElement` + `FormulaEditor`, `Autocompletion` API. ProseMirror: details, tables, font size/color, captions. `CONFIG[documentName].embedHandlers`. `DocumentSheet` ownership button. Hot reload for CSS via @import; hotReload render gets file context.
- World packages no longer installable from Setup (use Adventure documents). Rolls: booleans evaluate as 0/1.
- Assistant GMs get more permissions (except FILES_UPLOAD, MACRO_SCRIPT, SETTINGS_MODIFY).
